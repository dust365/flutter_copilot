# Flutter Copilot MCP 项目说明文档

## 📖 项目简介

**Flutter Copilot MCP** 是一个基于 MCP（Model Context Protocol）协议的服务器，专门用于让 AI 代理（如 Cursor、Claude Code 等）与运行中的 Flutter 应用程序进行交互。

### 核心定位

> **"Flutter 应用的 Playwright MCP/Cursor Browser"**

Flutter Copilot MCP 使 AI 代理能够直接连接到运行中的应用，查看 widget 树、点击元素、输入文本、滚动页面、捕获截图，实现自动化冒烟测试和交互。

### 设计理念

- **轻量级设计**：保持接口简洁，只暴露少量高价值操作
- **最小化数据返回**：只返回必要的可操作数据，保持上下文简洁
- **专注运行时交互**：与官方 Flutter MCP（开发时任务）不同，专注于运行时交互

---

## 🎯 项目特点

### 1. 与官方 Flutter MCP 的区别

| 特性 | 官方 Flutter MCP | Flutter Copilot MCP |
|------|----------------|----------------|
| **主要用途** | 开发时任务 | 运行时交互 |
| **功能** | 搜索 pub.dev、管理依赖、分析代码、检查运行时错误 | 点击按钮、输入文本、滚动、截图 |
| **实现方式** | 通过 Flutter Driver（需要额外测试代码） | 通过 VM Service（最小化代码改动） |
| **使用场景** | 构建应用 | 测试和交互应用 |

### 2. 核心优势

- ✅ **最小化改动**：只需在应用中初始化 `Flutter CopilotBinding`
- ✅ **无需额外测试代码**：不需要编写专门的测试代码
- ✅ **支持自定义组件**：可配置识别自定义交互组件
- ✅ **轻量级**：保持接口简洁，上下文大小可控

### 项目结构

```
flutter_copilot_mcp/
├── packages/
│   ├── flutter_copilot_mcp/          # MCP 服务器包
│   │   ├── bin/                  # 可执行文件
│   │   ├── lib/                  # 核心库代码
│   │   └── example/              # 示例应用
│   └── flutter_copilot_claw/       # Flutter 集成包
│       ├── lib/                  # Flutter 绑定代码
│       └── example/              # 示例应用
├── example/                      # 主示例应用
├── tool/                         # 构建工具
└── .vscode/                      # VS Code 配置
    ├── launch.json               # 调试配置
    └── settings.json             # 编辑器设置
```

### 工作原理

1. **初始化阶段**
   - Flutter 应用初始化 `Flutter CopilotBinding`
   - 注册自定义 VM Service 扩展（`ext.flutter.flutter_copilot.*`）

2. **连接阶段**
   - MCP 服务器通过 VM Service URI 连接到运行中的应用
   - URI 格式：`ws://127.0.0.1:PORT/ws`

3. **交互阶段**
   - AI 代理调用工具（如 `tap`）
   - MCP 服务器将调用转换为对应的 VM Service 扩展调用
   - Flutter 应用执行操作（如模拟点击手势）并返回结果

## 🚀 快速开始

### 前置条件

- Flutter SDK 已安装
- Dart SDK 3.6.0 或更高版本
- 应用必须在 Debug 或 Profile 模式下运行（Release 模式不支持）

### 安装步骤

#### 1. 安装 MCP 服务器

**方式一：全局安装（推荐）**

```bash
dart pub global activate flutter_copilot_mcp
```

**方式二：作为开发依赖安装**

```bash
dart pub add dev:flutter_copilot_mcp
```

#### 2. 在 Flutter 应用中添加包

```bash
flutter pub add flutter_copilot_claw
```

#### 3. 初始化 Flutter CopilotBinding

在 `main.dart` 中添加：

```dart
import 'package:flutter/foundation.dart';
import 'package:flutter/material.dart';
import 'package:flutter_copilot_claw/flutter_copilot_claw.dart';

void main() {
  // 仅在 Debug 模式下初始化 Flutter Copilot
  if (kDebugMode) {
    Flutter CopilotBinding.ensureInitialized();
  } else {
    WidgetsFlutterBinding.ensureInitialized();
  }

  runApp(const MyApp());
}
```

#### 4. 配置 AI 工具

**Cursor 配置**（`.cursor/mcp.json` 或 `~/.cursor/mcp.json`）：

```json
{
  "mcpServers": {
    "flutter_copilot": {
      "command": "flutter_copilot_mcp",
      "args": []
    }
  }
}
```

**Claude Code 配置**：

```bash
claude mcp add --transport stdio flutter_copilot -- flutter_copilot_mcp
```

#### 5. 运行应用并连接

1. 在 Debug 模式下运行 Flutter 应用：
   ```bash
   flutter run
   ```

2. 从控制台输出中找到 VM Service URI：
   ```
   The Flutter DevTools debugger and profiler on Chrome is available at: 
   http://127.0.0.1:9101?uri=ws://127.0.0.1:9101/ws
   ```

3. 使用 AI 代理连接到应用：
   ```
   连接到 ws://127.0.0.1:9101/ws
   ```

## 🛠️ MCP 支持的功能

### 1. 连接管理

#### `connect` - 连接到应用

连接到 Flutter 应用的 VM Service。

**参数：**
- `uri` (必需): VM Service URI，格式为 `ws://127.0.0.1:PORT/ws`

**示例：**
```
连接到 ws://127.0.0.1:50768/hi5uITDsNW4=/ws
```

#### `disconnect` - 断开连接

断开当前连接的应用。

---

### 2. UI 元素检测

#### `get_interactive_elements` - 获取可交互元素

返回屏幕上所有可交互 UI 元素的列表（按钮、输入框等）。

**特点：**
- 自动过滤布局组件（如 `Padding`、`Container`、`Column` 等）
- 只返回可操作元素，提供简洁的列表
- 包含元素类型、文本内容、位置信息等

**返回信息包括：**
- 元素类型（如 `FloatingActionButton`、`TextField`）
- 文本内容
- 位置和大小（bounds）
- 可见性状态
- 其他属性（如 tooltip、key 等）

---

### 3. 用户交互

#### `tap` - 点击元素

点击匹配指定条件的元素。

**匹配方式（按优先级）：**
1. **通过 key 匹配**（最可靠）：`ValueKey<String>`
2. **通过文本内容匹配**：元素的可见文本
3. **通过类型匹配**：widget 类型（如 `FloatingActionButton`）
4. **通过坐标匹配**：屏幕坐标位置

**参数：**
- `key` (可选): 元素的 key
- `text` (可选): 元素的可见文本
- `type` (可选): widget 类型名称
- `coordinates` (可选): 屏幕坐标 `{x: number, y: number}`

**示例：**
```dart
// 在 Flutter 代码中添加 key
ElevatedButton(
  key: ValueKey('submit_button'),
  onPressed: () {},
  child: Text('提交'),
)
```

#### `enter_text` - 输入文本

在匹配指定 key 的文本框中输入文本。

**参数：**
- `key` (必需): 文本框的 key
- `input` (必需): 要输入的文本

**示例：**
```
在 key 为 'email_field' 的文本框中输入 'user@example.com'
```

#### `scroll_to` - 滚动到元素

滚动视图直到匹配的元素可见。

**参数：**
- `key` (可选): 元素的 key
- `text` (可选): 元素的可见文本

---

### 4. 调试与监控

#### `get_logs` - 获取应用日志

获取自上次检查以来收集的应用日志。

**重要说明：**
- 需要应用使用 Dart 的 `logging` 包
- 日志通过 `Logger.root.onRecord` 收集
- 如果应用不使用 `logging` 包，此功能可能返回空结果

**使用示例：**
```dart
import 'package:logging/logging.dart';

final logger = Logger('MyApp');

void someFunction() {
  logger.info('执行某个操作');
  logger.warning('这是一个警告');
  logger.severe('这是一个错误');
}
```

#### `take_screenshots` - 捕获截图

捕获所有活动视图的截图，返回 base64 编码的图片。

**特点：**
- 默认将截图缩放到 2000×2000 像素以内
- 可通过 `Flutter CopilotConfiguration.maxScreenshotSize` 配置
- 设置为 `null` 可禁用缩放

---

### 5. 开发辅助

#### `hot_reload` - 热重载

执行 Flutter 应用的热重载，应用代码更改而不丢失状态。

**使用场景：**
- 修改代码后快速验证更改
- 保持应用状态的同时应用代码更新

## ⚙️ 高级配置

### 自定义设计系统支持

如果应用使用自定义组件，可以配置 Flutter Copilot 识别它们：

```dart
import 'package:flutter/foundation.dart';
import 'package:flutter/material.dart';
import 'package:flutter_copilot_claw/flutter_copilot_claw.dart';
import 'package:my_app/design_system/buttons.dart';
import 'package:my_app/design_system/inputs.dart';

void main() {
  if (kDebugMode) {
    Flutter CopilotBinding.ensureInitialized(
      Flutter CopilotConfiguration(
        // 识别自定义交互组件
        isInteractiveWidget: (type) =>
            type == MyPrimaryButton ||
            type == MyTextField ||
            type == MyCheckbox,

        // 从自定义组件中提取文本
        extractText: (widget) {
          if (widget is MyText) return widget.data;
          if (widget is MyTextField) return widget.controller?.text;
          return null;
        },
      ),
    );
  } else {
    WidgetsFlutterBinding.ensureInitialized();
  }

  runApp(const MyApp());
}
```

### 截图大小配置

```dart
Flutter CopilotConfiguration(
  maxScreenshotSize: 3000, // 设置最大尺寸为 3000×3000
  // 或设置为 null 禁用缩放
  // maxScreenshotSize: null,
)
```

## ⚠️ 注意事项与限制

### 1. VM Service URI

- **推荐手动粘贴 URI**：虽然某些工具可以自动发现 VM Service 端点，但最可靠的方式是从 `flutter run` 输出中复制 `ws://.../ws` URI
- **查找 URI**：运行 `flutter run` 后，查找类似这样的输出：
  ```
  The Flutter DevTools debugger and profiler on iPhone 15 Pro is available at: 
  http://127.0.0.1:9101?uri=ws://127.0.0.1:9101/ws
  ```
  使用 `ws://...` 部分

### 2. 模式限制

- **仅支持 Debug/Profile 模式**：Flutter Copilot 依赖 VM Service，在 Release 模式下不可用
- **必须在 Debug 模式下运行**：确保应用以 `flutter run` 或 Debug 模式启动

### 3. AI 代理的限制

- **代理可能不了解你的应用**：Flutter Copilot 可以"看到" widget 树并交互，但不会自动理解你的产品流程、命名约定或边界情况
- **提供上下文**：为了可靠的导航和断言，在提示中提供额外上下文：
  - 要到达的界面
  - 预期的标签/keys
  - 前置条件
  - 交互目标

### 4. 元素匹配

- **优先使用 key**：`ValueKey<String>` 是最可靠的匹配方式
- **添加 key**：如果无法定位 widget，可能需要在 Flutter 源代码中添加 `ValueKey`：
  ```dart
  ElevatedButton(
    key: ValueKey('submit_button'),
    onPressed: () {},
    child: Text('提交'),
  )
  ```

### 5. 交互的变异性

- **尽力而为的实现**：某些操作通过尽力而为的用户行为模拟实现（手势、焦点、文本输入、滚动）
- **结果可能不同**：根据平台、自定义组件、覆盖层或应用特定的手势处理，结果可能有所不同
- **改进建议**：
  - 如果流程不稳定，考虑暴露更清晰的 widget keys
  - 简化点击目标
  - 为设计系统添加自定义 `Flutter CopilotConfiguration` 钩子

## 🔧 故障排除

### 问题 1："Not connected to any app"

**原因：** AI 代理在使用其他工具之前没有调用 `connect`

**解决方案：** 确保先调用 `connect` 并提供有效的 VM Service URI

### 问题 2：找不到元素

**可能原因：**
- Widget 不可见
- 使用了自定义组件但未配置

**解决方案：**
- 确保 widget 在屏幕上可见
- 如果使用自定义组件，在 `Flutter CopilotConfiguration` 中配置它们

### 问题 3：日志为空

**原因：** 应用没有使用 `logging` 包

**解决方案：**
- 添加 `logging` 包依赖
- 使用 `Logger` 记录日志
- 配置 `Logger.root.onRecord` 监听器

### 问题 4：Release 模式不工作

**原因：** Flutter Copilot 依赖 VM Service，只在 Debug/Profile 模式下可用

**解决方案：** 确保应用在 Debug 或 Profile 模式下运行

## 🎓 最佳实践

### 1. 为重要元素添加 Key

```dart
// ✅ 推荐：为重要按钮添加 key
ElevatedButton(
  key: ValueKey('login_button'),
  onPressed: () {},
  child: Text('登录'),
)

// ❌ 不推荐：没有 key，只能通过文本匹配

  onPressed: () {},
  child: Text('登录'),
)
```

### 2. 使用 logging 包记录日志

```dart
import 'package:logging/logging.dart';

final logger = Logger('MyFeature');

void performAction() {
  logger.info('开始执行操作');
  try {
    // 执行操作
    logger.info('操作成功');
  } catch (e) {
    logger.severe('操作失败: $e');
  }
}
```

### 3. 配置自定义组件

如果使用自定义设计系统，务必配置 `Flutter CopilotConfiguration`：

```dart
Flutter CopilotBinding.ensureInitialized(
  Flutter CopilotConfiguration(
    isInteractiveWidget: (type) => 
        type == MyCustomButton ||
        type == MyCustomTextField,
  ),
);
```

### 4. 提供清晰的上下文

与 AI 代理交互时，提供清晰的上下文：

```
连接到应用，导航到用户设置页面（通过点击底部导航栏的"设置"标签），
找到"清除缓存"按钮（key 为 'clear_cache_button'），
点击它，然后检查日志确认操作是否成功。
```
