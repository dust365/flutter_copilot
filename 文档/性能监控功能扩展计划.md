## 🎯 项目概述

### 目标

扩展 Flutter Copilot MCP 工具集，添加性能监控相关功能，使 AI 智能体能够：
- 实时监控 Flutter 应用的性能指标
- 检测性能问题和瓶颈
- 分析帧渲染性能
- 监控内存使用情况
- 追踪 Widget 重建性能
- 生成性能报告

### 价值

1. **自动化性能测试**：AI 智能体可以自动执行性能测试，无需人工干预
2. **性能回归检测**：在代码变更后自动检测性能退化
3. **性能优化指导**：提供详细的性能数据，帮助开发者优化应用
4. **持续监控**：支持长期性能监控和趋势分析

## 📊 功能需求分析

### 核心功能模块

#### 1. 帧渲染性能监控 ⭐⭐⭐⭐⭐

**功能描述：**
监控应用的帧渲染性能，包括 FPS（每秒帧数）、帧时间、Jank（卡顿）检测等。

**关键指标：**
- 当前 FPS
- 平均 FPS
- 最低 FPS
- Jank 次数（帧时间超过 16.67ms 的帧）
- 帧时间分布（P50, P90, P99）

**使用场景：**
- 检测滚动列表的流畅度
- 验证动画性能
- 识别性能瓶颈
- 性能回归测试

**技术可行性：** ⭐⭐⭐⭐⭐ **极高**
- Flutter 提供了 `SchedulerBinding` 和 `FrameTiming` API
- 可以监听每一帧的渲染时间
- 实现相对简单

---

#### 2. 内存使用监控 ⭐⭐⭐⭐⭐

**功能描述：**
监控应用的内存使用情况，包括堆内存、图像缓存、对象数量等。

**关键指标：**
- 当前内存使用量（MB）
- 峰值内存使用量
- 内存增长趋势
- 对象数量统计
- 图像缓存大小

**使用场景：**
- 检测内存泄漏
- 监控内存峰值
- 优化内存使用
- 内存压力测试

**技术可行性：** ⭐⭐⭐⭐ **高**
- Dart VM 提供内存统计 API
- 可以通过 `dart:developer` 获取内存信息
- 需要平台特定 API 获取详细内存数据

---

#### 3. Widget 重建追踪 ⭐⭐⭐⭐

**功能描述：**
追踪 Widget 的重建次数和频率，识别不必要的重建。

**关键指标：**
- Widget 重建次数
- 重建频率最高的 Widget
- 重建原因（setState、InheritedWidget 变化等）
- 重建时间统计

**使用场景：**
- 优化 Widget 重建
- 识别性能热点
- 验证优化效果
- 调试状态管理问题

**技术可行性：** ⭐⭐⭐⭐ **高**
- 可以通过 `WidgetInspectorService` 获取 Widget 树信息
- 需要 Hook 到 Widget 的 build 方法
- 实现复杂度中等

---

#### 4. 构建时间分析 ⭐⭐⭐⭐

**功能描述：**
分析 Widget 构建方法的执行时间，识别慢构建的 Widget。

**关键指标：**
- 构建时间（ms）
- 最慢的构建方法
- 构建时间分布
- 构建调用栈

**使用场景：**
- 优化构建性能
- 识别慢构建的 Widget
- 性能瓶颈分析
- 代码优化验证

**技术可行性：** ⭐⭐⭐⭐ **高**
- 可以通过 `Timeline` API 追踪构建时间
- 需要 Hook 到 build 方法
- 实现复杂度中等

---

#### 5. 性能追踪（Timeline） ⭐⭐⭐⭐

**功能描述：**
开始和停止性能追踪，记录特定操作的性能数据。

**关键指标：**
- Timeline 事件
- 操作执行时间
- 调用栈信息
- 性能火焰图数据

**使用场景：**
- 分析特定操作的性能
- 生成性能报告
- 性能优化验证
- 深度性能分析

**技术可行性：** ⭐⭐⭐⭐ **高**
- Flutter 提供了 `Timeline` API
- 可以记录自定义事件
- 支持导出 Timeline 数据

---

#### 6. 性能快照 ⭐⭐⭐⭐

**功能描述：**
在特定时间点捕获应用的完整性能状态。

**关键指标：**
- 当前 FPS
- 内存使用
- Widget 树大小
- 活动对象数量
- 性能指标快照

**使用场景：**
- 性能基准测试
- 性能对比分析
- 性能报告生成
- 性能回归检测

**技术可行性：** ⭐⭐⭐⭐⭐ **极高**
- 组合使用上述各项指标
- 实现简单，主要是数据收集

### 数据流

1. **AI 智能体请求性能数据**
   - 通过 MCP 协议调用性能工具
   - MCP 服务器接收请求

2. **VM Service 调用**
   - MCP 服务器通过 VM Service 调用 Flutter 应用的扩展
   - 传递参数（如监控时长、采样间隔等）

3. **性能数据收集**
   - Flutter 应用中的性能服务收集数据
   - 使用 Flutter/Dart 提供的性能 API
   - 聚合和分析数据

4. **数据返回**
   - 性能数据通过 VM Service 返回
   - MCP 服务器格式化数据
   - 返回给 AI 智能体

## 🔧 功能模块设计

### 1. FramePerformanceMonitor（帧性能监控器）

**位置：** `packages/flutter_copilot_claw/lib/src/services/performance/frame_performance_monitor.dart`

**职责：**
- 监听每一帧的渲染时间
- 计算 FPS
- 检测 Jank（卡顿）
- 统计帧时间分布

**核心 API：**
```dart
class FramePerformanceMonitor {
  // 开始监控
  void startMonitoring({Duration? duration});
  
  // 停止监控
  void stopMonitoring();
  
  // 获取当前 FPS
  double getCurrentFps();
  
  // 获取平均 FPS
  double getAverageFps();
  
  // 获取 Jank 次数
  int getJankCount();
  
  // 获取帧时间统计
  FrameTimingStats getTimingStats();
  
  // 获取性能报告
  FramePerformanceReport getReport();
}
```

**实现要点：**
- 使用 `SchedulerBinding.instance.addTimingsCallback()` 监听帧时间
- 使用滑动窗口计算平均 FPS
- 检测帧时间超过 16.67ms 的帧（60 FPS 标准）

---

### 2. MemoryMonitor（内存监控器）

**位置：** `packages/flutter_copilot_claw/lib/src/services/performance/memory_monitor.dart`

**职责：**
- 监控堆内存使用
- 统计对象数量
- 检测内存增长趋势
- 识别潜在的内存泄漏

**核心 API：**
```dart
class MemoryMonitor {
  // 开始监控
  void startMonitoring({Duration? interval});
  
  // 停止监控
  void stopMonitoring();
  
  // 获取当前内存使用（MB）
  double getCurrentMemoryUsage();
  
  // 获取峰值内存使用（MB）
  double getPeakMemoryUsage();
  
  // 获取内存增长趋势
  List<MemorySnapshot> getMemoryTrend();
  
  // 获取对象统计
  ObjectStatistics getObjectStatistics();
  
  // 检测内存泄漏
  MemoryLeakReport? detectMemoryLeak();
}
```

**实现要点：**
- 使用 `dart:developer` 的 `getCurrentRss()` 获取内存使用
- 定期采样内存数据
- 分析内存增长趋势
- 检测异常的内存增长

---

### 3. WidgetRebuildTracker（Widget 重建追踪器）

**位置：** `packages/flutter_copilot_claw/lib/src/services/performance/widget_rebuild_tracker.dart`

**职责：**
- 追踪 Widget 的重建次数
- 分析重建频率
- 识别重建热点
- 记录重建原因

**核心 API：**
```dart
class WidgetRebuildTracker {
  // 开始追踪
  void startTracking();
  
  // 停止追踪
  void stopTracking();
  
  // 记录 Widget 重建
  void recordRebuild(String widgetType, String? key, RebuildReason reason);
  
  // 获取重建统计
  Map<String, RebuildStatistics> getRebuildStatistics();
  
  // 获取重建热点（Top N）
  List<RebuildHotspot> getRebuildHotspots({int topN = 10});
  
  // 获取重建报告
  WidgetRebuildReport getReport();
}
```

**实现要点：**
- 使用 `WidgetInspectorService` 获取 Widget 信息
- Hook 到 Widget 的 build 方法（需要特殊处理）
- 统计每个 Widget 的重建次数和频率
- 分析重建原因（setState、InheritedWidget 变化等）

### 4. BuildTimeAnalyzer（构建时间分析器）

**位置：** `packages/flutter_copilot_claw/lib/src/services/performance/build_time_analyzer.dart`

**职责：**
- 分析 Widget 构建方法的执行时间
- 识别慢构建的 Widget
- 记录构建调用栈

**核心 API：**
```dart
class BuildTimeAnalyzer {
  // 开始分析
  void startAnalysis();
  
  // 停止分析
  void stopAnalysis();
  
  // 记录构建时间
  void recordBuildTime(String widgetType, Duration buildTime, StackTrace? stackTrace);
  
  // 获取构建时间统计
  Map<String, BuildTimeStatistics> getBuildTimeStatistics();
  
  // 获取最慢的构建（Top N）
  List<SlowBuild> getSlowestBuilds({int topN = 10});
  
  // 获取构建时间报告
  BuildTimeReport getReport();
}
```

**实现要点：**
- 使用 `Timeline` API 记录构建事件
- 在 Widget 的 build 方法前后记录时间
- 分析构建时间分布
- 识别构建性能瓶颈

### 5. TimelineRecorder（Timeline 记录器）

**位置：** `packages/flutter_copilot_claw/lib/src/services/performance/timeline_recorder.dart`

- 开始和停止性能追踪

**核心 API：**
```dart
class TimelineRecorder {

  void startTrace(String traceName);

  void stopTrace();
  
  // 记录自定义事件
  void recordEvent(String eventName, {Map<String, dynamic>? data});

**实现要点：**

### 6. PerformanceService（性能服务）

**位置：** `packages/flutter_copilot_claw/lib/src/services/performance/performance_service.dart`

**职责：**

class PerformanceService {

  final MemoryMonitor memoryMonitor;

  // 停止全面监控

```

## 🔍 技术实现细节

### 1. 帧性能监控实现

**关键技术：**
- `SchedulerBinding.instance.addTimingsCallback()` - 监听帧时间
- `FrameTiming` - 帧时间数据
- 滑动窗口算法 - 计算平均 FPS

**代码示例：**
```dart
class FramePerformanceMonitor {
  final List<FrameTiming> _frameTimings = [];
  final int _maxSamples = 120; // 保留最近 120 帧（约 2 秒，60 FPS）
  
  void startMonitoring() {
    SchedulerBinding.instance.addTimingsCallback(_onFrameTiming);
  }
  
  void _onFrameTiming(List<FrameTiming> timings) {
    _frameTimings.addAll(timings);
    
    // 保持最近 N 帧
    if (_frameTimings.length > _maxSamples) {
      _frameTimings.removeRange(0, _frameTimings.length - _maxSamples);
    }
  }
  
  double getCurrentFps() {
    if (_frameTimings.isEmpty) return 0.0;
    
    final recentTimings = _frameTimings.takeLast(60);
    final totalTime = recentTimings.fold<double>(
      0.0,
      (sum, timing) => sum + timing.totalSpan.inMicroseconds,
    );
    
    if (totalTime == 0) return 0.0;
    return (recentTimings.length * 1000000) / totalTime;
  }
  
  int getJankCount() {
    const jankThreshold = Duration(microseconds: 16670); // 16.67ms for 60 FPS
    return _frameTimings.where((timing) => 
      timing.totalSpan > jankThreshold
    ).length;
  }
}
```

### 2. 内存监控实现

**关键技术：**
- `dart:developer` - 获取内存信息
- 定期采样 - 收集内存数据
- 趋势分析 - 检测内存泄漏

**代码示例：**
```dart
import 'dart:developer' as developer;

class MemoryMonitor {
  final List<MemorySnapshot> _snapshots = [];
  Timer? _samplingTimer;
  
  void startMonitoring({Duration interval = const Duration(seconds: 1)}) {
    _samplingTimer = Timer.periodic(interval, (_) {
      final memory = _getCurrentMemory();
      _snapshots.add(MemorySnapshot(
        timestamp: DateTime.now(),
        memoryUsage: memory,
      ));
      
      // 保持最近 1 小时的数据
      final oneHourAgo = DateTime.now().subtract(const Duration(hours: 1));
      _snapshots.removeWhere((s) => s.timestamp.isBefore(oneHourAgo));
    });
  }
  
  double _getCurrentMemory() {
    // 获取当前 RSS（Resident Set Size）内存使用（字节）
    final rss = developer.getCurrentRss();
    return rss / (1024 * 1024); // 转换为 MB
  }
  
  MemoryLeakReport? detectMemoryLeak() {
    if (_snapshots.length < 10) return null;
    
    // 分析最近 10 个采样点的内存增长趋势
    final recent = _snapshots.takeLast(10).toList();
    final growth = recent.last.memoryUsage - recent.first.memoryUsage;
    final growthRate = growth / recent.length;
    
    // 如果内存持续增长且增长率超过阈值，可能发生内存泄漏
    if (growthRate > 1.0) { // 每秒增长超过 1MB
      return MemoryLeakReport(
        detected: true,
        growthRate: growthRate,
        recommendation: '检查是否有未释放的资源或循环引用',
      );
    }
    
    return null;
  }
}
```

### 4. Timeline 追踪实现

**关键技术：**
- `Timeline` API - 记录事件
- 自定义事件标记 - 标记关键操作
- Timeline 数据导出 - 导出为 JSON

**代码示例：**
```dart
import 'dart:developer' as developer;

class TimelineRecorder {
  String? _currentTraceName;
  final List<TimelineEvent> _events = [];
  
  void startTrace(String traceName) {
    _currentTraceName = traceName;
    _events.clear();
    
    developer.Timeline.startSync('flutter_copilot:$traceName');
  }
  
  void stopTrace() {
    if (_currentTraceName != null) {
      developer.Timeline.finishSync();
      _currentTraceName = null;
    }
  }
  
  void recordEvent(String eventName, {Map<String, dynamic>? data}) {
    developer.Timeline.instantSync(
      'flutter_copilot:$eventName',
      arguments: data,
    );
  }
  
  String exportTimelineData() {
    // 导出 Timeline 数据为 JSON 格式
    // 可以导入到 Flutter DevTools 分析
    return jsonEncode({
      'traceEvents': _events.map((e) => e.toJson()).toList(),
    });
  }
}
```

## ⚠️ 风险评估

### 技术风险

1. **Widget 重建追踪的实现难度**
   - **风险：** Flutter 没有直接 Hook build 方法的 API
   - **影响：** 可能需要使用复杂的技术或限制功能
   - **缓解：** 先实现简化版本，后续逐步增强

2. **性能监控本身的开销**
   - **风险：** 性能监控可能影响应用性能
   - **影响：** 监控数据不准确或影响用户体验
   - **缓解：** 优化监控实现，使用采样和异步处理

3. **平台差异**
   - **风险：** 不同平台的内存 API 可能不同
   - **影响：** 某些功能可能在某些平台上不可用
   - **缓解：** 提供平台检测和降级方案

2. **功能完整性**
   - **风险：** 某些高级功能可能无法实现
   - **影响：** 功能不完整
   - **缓解：** 分阶段实现，优先实现核心功能
