## 技术实现说明

### 元素匹配机制

Flutter Copilot 使用以下优先级匹配元素：

1. **Key 匹配**（最可靠）：使用 `ValueKey<String>` 进行精确匹配
2. **文本匹配**：通过元素的文本内容匹配
3. **类型匹配**：通过 widget 类型匹配
4. **坐标匹配**：最后使用屏幕坐标匹配

### 测试中使用的匹配方式

本次测试全部使用 **Key 匹配**，这是最可靠的方式：

```dart
// 示例：ElevatedButton 定义
ElevatedButton(
  key: const ValueKey('test_elevated_button'),
  onPressed: () { ... },
  child: const Text('点击我 (ElevatedButton)'),
)
```

### 点击实现

`tap` 工具通过以下步骤实现点击：

1. 使用 `get_interactive_elements` 获取所有可交互元素
2. 根据提供的 key/text/type 参数匹配元素
3. 获取元素的坐标位置
4. 使用 Flutter 的 `GestureDispatcher` 模拟点击事件
5. 触发元素的 `onPressed` 或 `onTap` 回调

### 最佳实践建议

1. **优先使用 Key**: 在开发时为重要交互元素添加 `ValueKey<String>`
2. **Key 命名规范**: 使用有意义的 key 名称，如 `submit_button`、`login_form_email`
3. **避免重复 Key**: 确保同一页面内 key 唯一
4. **文本匹配备选**: 当无法添加 key 时，可以使用文本内容匹配
