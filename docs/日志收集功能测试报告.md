## 技术实现说明

### 日志收集机制

1. **Zone 拦截**: 使用 `runZonedGuarded` 和 `ZoneSpecification.print` 拦截所有 `print()` 调用
2. **日志存储**: 使用 `LogCollector` 类存储日志，最多保存 1000 条
3. **VM Service Extension**: 通过 `flutter_copilot.getLogs` 扩展暴露日志获取接口
4. **MCP 工具**: `get_logs` 工具调用 VM Service Extension 获取日志

### 日志格式

```
[时间戳][日志类型][来源] 日志内容
```

示例：
```
[21:02:11.781][CONSOLE] Console output: 这是一条信息日志 #1
[21:02:13.587][CONSOLE] Console error: 捕获到异常: Exception: ...
```
